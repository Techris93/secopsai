Item 1 of 8

Flyto2 Core: Arbitrary file write via unguarded data.*/file.* modules (incomplete fix of CVE-2026-67429)

CriticalCVSS 10

Source-reported by GitHub Security Advisories.

CVE-2026-77312 (official CVSS 10): Flyto2 Core is an execution kernel for automation and AI-agent workflows. Prior to 2.26.8, the earlier CVE-2026-67429 remediation applied validate_path_with_env_config() to only a hand-picked set of file-writing modules, leaving data.csv.write in src/core/modules/atomic/data/csv_write.py, data.json_to_csv in src/core/modules/atomic/data/json_to_csv.py, file.copy in src/core/modules/atomic/file/copy.py, and file.move in src/core/modules/atomic/file/move.py outside the FLYTO_SANDBOX_DIR confinement boundary.

What to do: Upgrade to a fixed release: flyto-core 2.26.8.

Item 2 of 8

Etherpad: Pre-auth arbitrary file read

CriticalCVSS 9.8

Source-reported by GitHub Security Advisories.

CVE-2026-114516 (official CVSS 9.8): On POSIX systems the sanitizer correctly treats backslashes as ordinary filename bytes, but the later conversion turns encoded backslash-separated parent-directory segments into traversal components without revalidation or containment. The expressPreSession registration and the always-present ep_etherpad-lite core pseudo-plugin make this path reachable without credentials, allowing a remote attacker to read any file available to the Etherpad process.

What to do: Upgrade to a fixed release: ep_etherpad-lite 3.3.3.

Guard Core: Quadratic ReDoS in built-in detection pattern freezes the event loop with a single request

HighCVSS 7.5

Source-reported by GitHub Security Advisories.

CVE-2026-129302 (official CVSS 7.5): From 3.5.0 until 3.13.0, built-in penetration-detection patterns in guard_core/handlers/suspatterns_handler.py execute through a direct pattern.search(content) call instead of the timeout-protected create_safe_matcher() path used for custom patterns. NLTK: Compile-time regex DoS in NLTK search/tokenizer sinks: quadratic regex-engine compile bypasses the match-only timeout

HighCVSS 7.5
