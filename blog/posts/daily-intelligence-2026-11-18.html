CVE-2026-115731: Perforce Puppet Enterprise Deserialization of Untrusted Data Vulnerability

CriticalCVSS 9.4Exploited (CISA KEV)

Source-reported by CISA Known Exploited Vulnerabilities.

CVE-2026-115731 (official CVSS 9.4 and 9.9): Deserialization of untrusted data in the report-processing code of Puppet, as used by Puppet Server, in the affected releases, allows a client that holds any CA-signed agent certificate to execute arbitrary code on the Puppet Server as its service user by submitting a report containing a crafted rich-data type via PUT request. Where the certificate authority autosigns requests without strong verification, an unauthenticated network attacker can obtain such a certificate. CISA lists it as exploited in the wild.

What to do: Apply the fix in the vendor's advisory (https://portal.perforce.com/s/cve/a91Qi000003IaHpIAK/report-deserialization-code-execution); the CVE record lists as affected: Puppet Enterprise 2023.8.0 before 2023.8.13; 2025.0.0 before 2025.12.1; 2026.0.0 before 2026.0.1. If no update or mitigation is available, take the product out of service.
