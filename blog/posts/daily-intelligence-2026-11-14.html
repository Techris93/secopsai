CVE-2026-114713: UnrealIRCd Improper Neutralization of Delimiters Vulnerability

HighCVSS 8.6Exploited (CISA KEV)

Source-reported by CISA Known Exploited Vulnerabilities.

CVE-2026-114713 (official CVSS 8.6): The labeled-response module in UnrealIRCd 6.0.0 before 6.2.7.1 does not escape the IRCv3 "label" message tag when echoing it into replies, which allows any user on a network with two or more linked servers to inject server-to-server commands that are executed with server authority. CISA lists it as exploited in the wild.

What to do: Apply the fix in the vendor's advisory (https://www.unrealircd.org/); the CVE record lists the fix in 6.2.7.1. If no update or mitigation is available, take the product out of service.

CVE-2026-123039: Check Point Multiple Products Incorrect Permission Assignment for Critical Resource Vulnerability

HighCVSS 7.8Exploited (CISA KEV)

Source-reported by CISA Known Exploited Vulnerabilities.

CVE-2026-123039 (official CVSS 7.8): An authenticated local user can send a command to the socket and have it executed as root. CISA lists it as exploited in the wild.

What to do: Apply the fix in the vendor's advisory (https://support.checkpoint.com/results/sk/sk1000362). If no update or mitigation is available, take the product out of service.
