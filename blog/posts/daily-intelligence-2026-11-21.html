CVE-2026-76466: Cisco Expressway Series Use of Hard-coded Credentials Vulnerability

CriticalCVSS 9.8Exploited (CISA KEV)

Source-reported by CISA Known Exploited Vulnerabilities.

CVE-2026-76466 (official CVSS 9.8): A vulnerability in the database service feature of Cisco Expressway Series could allow an unauthenticated, remote attacker with network access to a Cisco Expressway device to execute arbitrary operating system commands as&nbsp;root. This vulnerability is due to the use of persistent cookies. CISA lists it as exploited in the wild.

What to do: Apply the fix in the vendor's advisory (https://sec.cloudapps.cisco.com/security/center/content/CiscoSecurityAdvisory/cisco-sa-vcs-static-cred-hr7EWZ8t); the CVE record lists as affected: Cisco TelePresence Video Communication Server (VCS) Expressway X8.11.2; X8.6; X8.11.3; X8.2.2. If no update or mitigation is available, take the product out of service.

Item 2 of 4

CVE-2026-129448: Apache Roller Deserialization of Untrusted Data Vulnerability

CriticalCVSS 9.8Exploited (CISA KEV)

Source-reported by CISA Known Exploited Vulnerabilities.

CVE-2026-129448 (official CVSS 9.8): Deserialization of Untrusted Data in Apache Roller versions 4.0.0 through 6.1.4 allows an unauthenticated remote attacker to execute arbitrary code. The XML-RPC endpoint accepts vendor extension types and deserializes them before authenticating the requester. CISA lists it as exploited in the wild.

What to do: Apply the fix in the vendor's advisory (https://lists.apache.org/thread/cc0jck13nb9vvcmzxzwotr6n16mx28z9); versions 4.0.0 through 6.1.4 are affected. If no update or mitigation is available, take the product out of service.

Item 3 of 4

CVE-2026-123890: VMWare vCenter Authentication Bypass Using an Alternate Path or Channel Vulnerability

CriticalCVSS 9.8Exploited (CISA KEV)

Source-reported by CISA Known Exploited Vulnerabilities.

CVE-2026-123890 (official CVSS 9.8): VMware vCenter contains an authentication bypass vulnerability in the VMware Directory Service. Affected versions: 9.1.x (fixed in 9.1.1.0200); 9.0.x (fixed in 9.0.2.0200); 8.0 (fixed in 8.0 U3m); 5.x (fixed in 5.2.5). CISA lists it as exploited in the wild.

What to do: Apply the fix in the vendor's advisory (https://support.broadcom.com/web/ecx/support-content-notification/-/external/content/SecurityAdvisories/0/39495); the CVE record lists as affected: VMware vCenter 9.1.x before 9.1.1.0200; 9.0.x before 9.0.2.0200; 8.0 before 8.0 U3m; 5.x before 5.2.5; Telco Cloud Platform 3.0; 4.x; 5.0.x; 5.1.x; Telco Cloud Infrastructure 3.0. If no update or mitigation is available, take the product out of service.

svglib: Exponential resource consumption via nested <use> references in svg2rlg

HighCVSS 7.5

Source-reported by GitHub Security Advisories.

CVE-2026-132275 (official CVSS 7.5): A small attacker-controlled SVG can therefore trigger exponentially increasing node expansion, consuming excessive CPU and memory in any application that renders it without a non-default option; HTML-to-PDF workflows using xhtml2pdf can reach the same renderer when an embedded data:image/svg+xml image in an HTML img element is passed to pisa.CreatePDF(). This issue is fixed in 2.3.1.

What to do: Upgrade to a fixed release: svglib 2.3.1.
