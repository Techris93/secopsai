Active Storage: Possible arbitrary file write and read in image analysis

CriticalCVSS 9.8

Source-reported by GitHub Security Advisories.

CVE-2026-122006 (official CVSS 9.8): The activestorage gem before 8.1.4.1 for Ruby on Rails, when ImageMagick attachment processing occurs, can allow server read and write operations (e.g., reading secret_key_base) because the ImageMagick analyzer runs when a file is attached, and there is not an ImageMagick security policy to block unintended functionality.

What to do: Upgrade to a fixed release: activestorage 8.1.4.1, activestorage 8.0.5.2.
