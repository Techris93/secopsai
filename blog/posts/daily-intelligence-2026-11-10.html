CVE-2026-123218: IBM Aspera Faspex Incorrect Authorization Vulnerability

Source-reported by CISA Known Exploited Vulnerabilities.

CVE-2026-123218 (official CVSS 9.8): IBM Aspera Faspex 5.0.0 through 5.0.19 could allow an authorized user to craft a specific message to bypass user authorization and gain full administrative privileges. CISA lists it as exploited in the wild.

Defensive action: Apply the fix in the vendor's advisory (https://www.ibm.com/support/pages/node/7295921); the CVE record lists as affected: Aspera Faspex 5.0.0 through 5.0.19. If no update or mitigation is available, take the product out of service.

Limitations: Source-reported; SecOpsAI did not reproduce the issue.

CVE-2026-123158: OpenBSD OpenSSH Unexpected Status Code or Return Value Vulnerability

Source-reported by CISA Known Exploited Vulnerabilities.

CVE-2026-123158 (official CVSS 8.1): sshd in OpenSSH before 10.6p2 on Linux, when musl libc is used without PAM, lacks a workaround for a password authentication bypass (related to misinterpretation of whether a string is intended to be a password hash). For some configurations of accounts, any password between 256 and 1024 characters succeeds. CISA lists it as exploited in the wild.

Defensive action: Apply the vendor's security update; the CVE record lists the fix in 10.6p2. If no update or mitigation is available, take the product out of service.

Limitations: Source-reported; SecOpsAI did not reproduce the issue.

node-opcua: Namespace-Level RBAC Fail-Open - Anonymous Write/Call Bypass via Unbound `DefaultRolePermissions

Source-reported by GitHub Security Advisories.

CVE-2026-95860 (official CVSS 9.1): Servers with no declared policy, nodes with explicit per-node permissions, and correctly bound programmatic namespace metadata are outside the authorization-bypass case. This issue is fixed in version 2.180.0.

Defensive action: Upgrade to a fixed release: node-opcua 2.180.0, node-opcua-address-space 2.180.0, node-opcua-server 2.180.0.
