CVE-2026-116606: Barracuda Networks Email Security Gateway (ESG) Authentication Bypass Using an Alternate Path or Channel Vulnerability

CriticalCVSS 9.3Exploited (CISA KEV)

Source-reported by CISA Known Exploited Vulnerabilities.

CVE-2026-116606 (official CVSS 9.3): An authentication bypass in Barracuda Email Security Gateway versions earlier than 9.4.0.030 allows an unauthenticated remote attacker to invoke a configuration-import function and restore a crafted, compatible backup archive, resulting in unauthorized modification of the appliance’s global configuration. CISA lists it as exploited in the wild.

What to do: Apply the fix in the vendor's advisory (https://trust.barracuda.com/security/pre-authentication-authorization-bypass-command-injection); the CVE record lists as affected: Barracuda Email Security Gateway (ESG) before 9.4.0.030. If no update or mitigation is available, take the product out of service.

CVE-2026-111560: Barracuda Networks Multiple Products OS Command Injection Vulnerability

HighCVSS 8.6Exploited (CISA KEV)

Source-reported by CISA Known Exploited Vulnerabilities.

CVE-2026-111560 (official CVSS 8.6): Improper neutralization of shell metacharacters in the timezone configuration field in certain Barracuda appliance products using common Barracuda code allows an authenticated administrator to inject OS commands that execute with root privileges when the crafted timezone value is subsequently processed. CISA lists it as exploited in the wild.

What to do: Apply the fix in the vendor's advisory (https://trust.barracuda.com/security/pre-authentication-authorization-bypass-command-injection); the CVE record lists as affected: Barracuda Email Security Gateway (ESG) 9.4.0.27 and older; Barracuda Load Balancer Application Delivery Controller (ADC) 6.4.0 and older; Barracuda Web Application Firewall (WAF) 11.0.1 and older. If no update or mitigation is available, take the product out of service.

CVE-2026-20320: Cisco BroadWorks Improper Restriction of XML External Entity Reference Vulnerability

HighCVSS 7.5Exploited (CISA KEV)

Source-reported by CISA Known Exploited Vulnerabilities.

CVE-2026-20320 (official CVSS 7.5): A vulnerability in the Open Client Interface (OCI) XML Parser of Cisco BroadWorks could allow an unauthenticated, remote attacker to read sensitive configuration information on an affected system. This vulnerability exists because XML entries are improperly parsed due to external entity resolution being allowed by default. CISA lists it as exploited in the wild.

What to do: Apply the fix in the vendor's advisory (https://sec.cloudapps.cisco.com/security/center/content/CiscoSecurityAdvisory/cisco-sa-bworks-xxe-uwUd7CEt); the CVE record lists as affected: Cisco BroadWorks N/A. If no update or mitigation is available, take the product out of service.

Item 5 of 8

React: Unauthenticated Remote Code Execution in React Server Components

CriticalCVSS 9.5

Source-reported by GitHub Security Advisories.

CVE-2026-126187 (official CVSS 9.5): From 19.0.0 until 19.0.9, 19.1.10, 19.2.9, and 19.3.1, the react-server-dom-webpack, react-server-dom-parcel, and react-server-dom-turbopack packages are vulnerable to unauthenticated remote code execution through crafted payloads targeting frameworks that support React Server Components. The vulnerability only affects extremely rare cases where responses transport multiple typed arrays and an attacker-controlled value.

What to do: Upgrade to a fixed release: react-server-dom-parcel 19.0.9, react-server-dom-parcel 19.1.10, react-server-dom-parcel 19.2.9, react-server-dom-parcel 19.3.1, react-server-dom-turbopack 19.0.9, react-server-dom-turbopack 19.1.10, react-server-dom-turbopack 19.2.9, react-server-dom-turbopack 19.3.1, react-server-dom-webpack 19.0.9, react-server-dom-webpack 19.1.10, react-server-dom-webpack 19.2.9, react-server-dom-webpack 19.3.1.

Item 6 of 8

GitLab Critical Patch Release: 19.5.4, 19.4.6, 19.3.8

HighCVSS 7.5

Source-reported by GitLab Security Releases.

CVE-2026-105437 (official CVSS 7.5): Affected versions of Git have a heap buffer overflow in the three-way merge code (xdiff), which an attacker can trigger through a repository they control. When Git merges a file, it first adds up the size of the merged output, allocates a buffer of that size, and then writes the output into it.

What to do: Upgrade to a fixed release: 19.5.4, 19.4.6, 19.3.8.
