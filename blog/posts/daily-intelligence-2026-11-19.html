CVE-2026-90817: Vanderbilt University Research Electronic Data Capture (REDCap) Code Injection Vulnerability

CriticalCVSS 9.8Exploited (CISA KEV)

Source-reported by CISA Known Exploited Vulnerabilities.

CVE-2026-90817 (official CVSS 9.8): An unauthenticated Remote Code Execution vulnerability was found in the survey passthrough routing and Data Import processing logic, in which a malicious user could potentially exploit it by manipulating HTTP requests to access an unintended controller route from a public survey context and by supplying a crafted file-path/stream parameter during import handling. If successfully exploited, this could allow the attacker to remotely execute arbitrary code on the REDCap server. CISA lists it as exploited in the wild.

What to do: Apply the fix in the vendor's advisory (https://www.securifera.com/advisories/); the CVE record lists as affected: REDCap 13.3.0. If no update or mitigation is available, take the product out of service.

Item 2 of 9

CVE-2026-90436: Apache Axis Unsafe Reflection Vulnerability

CriticalCVSS 9.8Exploited (CISA KEV)

Source-reported by CISA Known Exploited Vulnerabilities.

CVE-2026-90436 (CVSS 9.8, scored by CISA; the vendor and NVD have not published a score): UNSUPPORTED WHEN ASSIGNED Deserialization of an inbound SOAP fault in Apache Axis 1.x allows unauthenticated remote class instantiation. When a SOAP <Fault> carries a <detail><exceptionName> element, Axis loads the named class and, if a String <data> element is also present, instantiates it through its String constructor before checking that it is an AxisFault. CISA lists it as exploited in the wild.

What to do: Apply the fix in the vendor's advisory (https://lists.apache.org/thread.html/8slf0j9gz35z56t0glt5h0ncwlbn4bdz); the CVE record lists as affected: Apache Axis 1.x (EOL) 1.4 and older; Apache Axis 1.x (EOL) 1.4 and older; Apache Axis 1.x (EOL) [HASH-REDACTED] before [HASH-REDACTED]. If no update or mitigation is available, take the product out of service.

Item 3 of 9

Jane: Instantiation RCE via parameter description -> raw PHPDoc */ breakout (jane-php/open-api-3)

CriticalCVSS 9.3

Source-reported by GitHub Security Advisories.

CVE-2026-63411 (official CVSS 9.3): A parameter description containing a PHPDoc closing delimiter can terminate the comment early and place attacker-controlled PHP in class-body position, including an __construct method that runs when the generated Client is instantiated. Exploitation requires generating a client from an attacker-influenced OpenAPI document and then using the generated SDK, and can execute arbitrary PHP with the consuming application's privileges.

What to do: Upgrade to a fixed release: jane-php/open-api-3 7.12.0.
