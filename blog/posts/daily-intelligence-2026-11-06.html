CVE-2026-118527: Ivanti Connect Secure Generation of Predictable Numbers or Identifiers Vulnerability

Source-reported by CISA Known Exploited Vulnerabilities.

CVE-2026-118527 (official CVSS 4.3): Use of predictable filenames in Ivanti Connect Secure before versions 25.1.1.3 and 22.8R2.6 allows a remote authenticated attacker to upload files with attacker-controlled content to a known location on disk. CISA lists it as exploited in the wild.

Defensive action: Apply the vendor's security update; the CVE record lists the fix in 25.1.1.3 and 22.8R2.6. If no update or mitigation is available, take the product out of service.

Limitations: Source-reported; SecOpsAI did not reproduce the issue.

Banks: Unsafe importlib.import_module of attacker-controlled Tool.import_path in CompletionExtension allows RCE

Source-reported by GitHub Security Advisories.

CVE-2026-61536 (official CVSS 7.5): There is no allowlist or sanitization on import_path, so any importable Python attribute (e.g. os.system, subprocess.getoutput) can be selected.

Defensive action: Upgrade to a fixed release: banks 2.4.3.

Limitations: Source-reported; SecOpsAI did not reproduce the issue.

dcmjs: DS/IS VALUE REPRESENTATION INPUT VALIDATION BYPASS

Source-reported by GitHub Security Advisories.

dcmjs, a JavaScript library for DICOM manipulation used in web-based medical imaging viewers, contains an input validation bypass in its handling of DS (Decimal String) and IS (Integer String) value representations.
