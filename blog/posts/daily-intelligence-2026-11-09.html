CVE-2026-19868: SonicWall SonicOS SSLVPN Use of Single-factor Authentication Vulnerability

Source-reported by CISA Known Exploited Vulnerabilities.

CVE-2026-19868 (CVSS 7.5, scored by CISA; SonicWall and NVD have not published a score): An authentication enforcement vulnerability in SonicOS SSLVPN service may allow a user with valid credentials for an alternate authentication method to bypass SAML authentication controls. Successful exploitation may also bypass SAML-enforced multi-factor authentication (MFA). CISA lists it as exploited in the wild.

Affected: SonicOS Gen7 7.3.3-7015 and older, and Gen8 8.2.2-8015 and older, according to the CVE record.

Defensive action: Apply the fix in SonicWall advisory SNWLID-2026-0014. If no update or mitigation is available, take the product out of service.

Limitations: Source-reported; SecOpsAI did not reproduce the issue.

Added to the CISA KEV catalog 6 Nov 2026; first seen by SecOpsAI 6 Nov 2026, 23:46 UTC.

fastapi-code-generator: Import-time RCE via response status-code key -> unescaped @app.get(..., responses={...}) dict

Source-reported by GitHub Security Advisories.

CVE-2026-63469 (official CVSS 9.3): A multi-response OpenAPI operation with an attacker-controlled or attacker-influenced second non-primary response key can close the dictionary-key literal and inject a valid Python expression. Syntax-breaking input only causes generation to fail, but syntactically valid generated code executes with the application's or CI process's privileges when the generated module is imported and its decorator arguments are evaluated.

Defensive action: Upgrade to a fixed release: fastapi-code-generator 0.8.1.

Limitations: Source-reported; SecOpsAI did not reproduce the issue.
