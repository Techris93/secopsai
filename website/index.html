SecOpsAI

A local-first security operations platform. It discovers network assets, monitors package registries, and turns telemetry into findings you can act on.

APPLICABILITY macOS · Linux · Windows · Edge sensors
DATA POLICY Local-first. No log shipping by default.
LICENSE MIT · Source available on GitHub

Purpose

Most small teams do not know which devices are on their network. They also do not know which packages their software depends on. SecOpsAI answers both questions on your own hardware.

The platform collects host, network, and registry telemetry. It stores the data in a local SQLite store. It correlates the data into findings. Each finding has evidence, a severity, and a next action.

SecOpsAI Edge is the network sensor module. SecOpsAI Research is the package-registry surveillance module. The dashboard is the operator console for both.

Installation

Select your platform. Run the command. The install takes less than five minutes.

PROC-01INSTALL — macOS 12+
curl -fsSL https://secopsai.dev/install.sh | bash

Requires macOS 12 or later. Nmap is required for Edge discovery. The installer checks for it.

PROC-02INSTALL — Debian / Ubuntu / RHEL
curl -fsSL https://secopsai.dev/install.sh | bash

Requires Python 3.10 or later. A systemd service keeps the Edge worker running.

PROC-03INSTALL — Windows (WSL2)
wsl --install -d Ubuntu

SecOpsAI runs in WSL2 on Windows. After WSL is ready, use the Linux procedure.

PROC-04INSTALL — OpenClaw plugin
openclaw plugins install secopsai

The OpenClaw plugin connects SecOpsAI to your local automation runtime.

NOTE
Scan only networks you own or have written permission to test. SecOpsAI refuses public IP ranges by default.

SecOpsAI is terminal-native. The example shows a standard operator session.

$ secopsai research score run

Safety boundaries

SecOpsAI is built to collect and analyze. It does not attack. These rules apply everywhere in the platform.

NOTE
Raw scan output and package artifacts stay on your machine. Cloud reports contain minimized findings only.
CAUTION
Package code is never executed during analysis. Static analysis is the default. Sandbox analysis needs your explicit approval.
WARNING
Do not scan networks you do not own. Unauthorized scanning can break the law in your jurisdiction. Use the dry-run preview before every scan.
