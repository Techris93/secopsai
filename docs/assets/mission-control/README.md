# Mission Control screenshots

These screenshots document the SecOpsAI Mission Control information
architecture with representative sample data. They must not contain real
tokens, credentials, customer records, private telemetry, or local-only paths.

The gallery covers:

- `overview.png`: priorities, review queues, and service health.
- `model-routing.png`: persisted primary-model selection and explicit ordered
  fallbacks.
- `research-pipeline.png`: safe package intake, evidence gates, and Research
  Case progression.
- `findings.png`: latest-first evidence-backed findings and response actions.
- `publications.png`: editorial review, approved media, staging, and deployment.
- `enterprise.png`: connector readiness, vulnerability priority, authorized
  DAST, governance, and assurance workflows.

When the UI changes materially, recapture all six images at the same desktop
viewport and re-check that every visible action and status label matches the
current product behavior.
