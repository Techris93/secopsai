# Contact SecOpsAI

Use the channel that matches your request. Do not include passwords, API keys,
customer data, or unredacted sensitive telemetry in an email.

## Security reports

For vulnerabilities in SecOpsAI, suspected abuse, security incidents, or other
security-sensitive disclosures, contact:

[security@secopsai.dev](mailto:security@secopsai.dev)

Include the affected component, a concise description, reproducible evidence
where safe, and a suggested contact method. Do not send live credentials or
weaponized payloads.

## Research and collaboration

For independent research, package ecosystem intelligence, responsible
disclosure coordination, research collaboration, or pilot questions, contact:

[research@secopsai.dev](mailto:research@secopsai.dev)

When reporting a package or campaign, include the ecosystem, package name and
version, registry URL, observation date, and links to public evidence where
available.
